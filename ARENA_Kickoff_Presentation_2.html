Projektziele & Mehrwert

Business Value

Das Portal soll Kunden ermöglichen, komplexe Bestellhistorien in Echtzeit zu analysieren und personalisierte Empfehlungen zu erhalten.

  • Erhöhung der Kundenbindung um 25%
  • Reduktion der Ladezeit auf unter 200ms

Die Fachlichkeit

Lernziele & Onboarding

Frontend Mastery

Vertiefung in React Hooks, Functional Components und State Management mit Context API.

Spring Boot Core

Beherrschung von Dependency Injection, JPA-Repositories und REST-Controller Pattern.

Secure Auth

Verständnis von OAuth2-Flows und Integration externer Identity Provider.

Systemarchitektur

Das System basiert auf einer klassischen 3-Tier-Architektur mit entkoppeltem Auth-Service:

  • Frontend: React (Single Page Application)
  • Backend: Spring Boot REST API
  • Identity: Externer IdP (Keycloak) für JWT-basierte Sicherheit
  • Data: PostgreSQL für relationale Persistenz
