✅ Definition of Done

Ein Feature ist erst „Done" wenn alle Kriterien erfüllt sind:

✓
Code Reviewed

Mindestens 1 Approval durch Peer + Tech Lead bei Architektur-Changes

✓
Tests > 80% Coverage

Unit Tests + Integration Tests, gemessen durch SonarQube

✓
Dokumentation aktualisiert

API-Docs, README, Confluence bei neuen Features/Änderungen

✓
CI Pipeline grün

Build, Tests, Linting & Security Checks bestanden

✓
PO Abnahme

Product Owner hat Feature in Review abgenommen
